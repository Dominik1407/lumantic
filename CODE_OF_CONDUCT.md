# Code of Conduct

Lumantic follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, critique ideas rather than people, and make
room for those who are new. Harassment, insults and personal attacks are not tolerated, whether
in issues, pull requests, discussions or anywhere else you represent the project.

## Reporting

Report unacceptable behaviour to the maintainer, [@Dominik1407](https://github.com/Dominik1407).
If it should not be discussed in public, use GitHub's private form under
**Security → Report a vulnerability** in this repository. It is meant for security issues, but
it is also the project's only private channel, so it is fine to use it for this.

Reports are handled confidentially. The maintainer may remove comments, close threads or block
people who break this code, as described in the Contributor Covenant.
