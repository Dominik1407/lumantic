# Logo «Baustein»

Erzeugt aus `web/src/logo.ts`, der einzigen Stelle, an der die App das Logo zeichnet. Ändert sich das Logo dort, diese
Dateien neu erzeugen.

| Datei | Was |
|---|---|
| `lumantic-logo.svg`, `-dunkel.svg` | Zeichen und Wortmarke, für helle und dunkle Gründe |
| `lumantic-zeichen.svg`, `-dunkel.svg` | nur das Zeichen: zwei Bausteine und ein Stern |
| `lumantic-wortmarke.svg`, `-dunkel.svg` | nur die Wortmarke, Sora 600 als Umriss |
| `lumantic-app-symbol.svg`, `-dunkel.svg` | das Zeichen auf einer Kachel, wie im Browser-Tab |
| `beispiel-firmenlogo-musterbank.svg` | ein erfundenes Firmenlogo, Beispiel für `brand.logo` |
